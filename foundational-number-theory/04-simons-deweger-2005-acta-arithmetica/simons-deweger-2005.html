1 1. บทนำและนิยาม \(m\)-Cycle (Introduction & \(m\)-Cycles)

กำหนดฟังก์ชันคอลลัทซ์ \(T: \mathbb{Z}^+ \to \mathbb{Z}^+\):

\[ T(n) = \begin{cases} \frac{3n+1}{2} & \text{ถ้า } n \text{ เป็นจำนวนคี่} \\ \frac{n}{2} & \text{ถ้า } n \text{ เป็นจำนวนคู่} \end{cases} \]

วัฏจักรพื้นฐาน (Trivial Cycle) คือ \(\{1, 2\}\) เนื่องจาก \(T(1) = 2\) และ \(T(2) = 1\)
คำถามสำคัญคือ: มีวัฏจักรอื่นบนจำนวนเต็มบวกที่มีค่ามากกว่า \(2\) (Nontrivial Cycle) หรือไม่?

1.1 นิยาม \(m\)-Cycle

วัฏจักรใด ๆ เรียกว่าเป็น \(m\)-Cycle ถ้าตัวเลขในวัฏจักรสามารถแบ่งออกเป็น \(m\) ช่วงย่อย โดยแต่ละช่วงประกอบด้วย:

  • ลำดับย่อยที่เพิ่มขึ้นของจำนวนคี่ (Increasing subsequence of odd numbers)
  • ตามด้วยลำดับย่อยที่ลดลงของจำนวนคู่ (Decreasing subsequence of even numbers)

นั่นคือ \(m\) หมายถึง จำนวนจุดต่ำสุดสัมพัทธ์ (Local Minima) หรือจำนวนยอดเขาในหนึ่งรอบวัฏจักร:

  • \(1\)-Cycle: มีเลขคี่เรียงติดกัน \(1\) ชุด แล้วหาร \(2\) รวดเดียวจนครบรอบ (พิสูจน์โดย Ray Steiner ปี 1977 ว่าไม่มี \(1\)-cycle อื่นนอกจาก \(\{1, 2\}\))
  • \(2\)-Cycle: มี \(2\) ยอดเขา (พิสูจน์โดย John Simons ปี 2004 ว่าไม่มี \(2\)-cycle อื่น)

ในเปเปอร์นี้ Simons และ de Weger ได้วางระเบียบวิธีทั่วไปสำหรับ \(m\)-cycle ใด ๆ

2 2. สมการไดโอแฟนไทน์ของวัฏจักร (The Diophantine Structure)

ให้วัฏจักรประกอบด้วยจำนวนคี่ทั้งหมด \(K\) ตัว และจำนวนคู่ทั้งหมด \(L\) ตัว (รวมความยาววัฏจักร \(N = K + L\))
ให้ \(x_{\min}\) แทนค่าที่น้อยที่สุดในวัฏจักร

จากการขยายผลคูณรอบวัฏจักร จะได้สมการไดโอแฟนไทน์แม่บท:

\[ x_{\min} \left( 2^{K+L} - 3^K \right) = \sum_{j=0}^{K-1} 3^{K-1-j} 2^{A_j} \tag{1}\]

โดยที่ \(0 = A_0 \le A_1 \le \dots \le A_{K-1} = L\) เป็นลำดับเลขชี้กำลัง

เนื่องจาก \(x_{\min} \ge 1\) และผลรวมทางขวามือเป็นบวกแท้จริง ทำให้ได้เงื่อนไขจำเป็นแรกทันที:

\[ 2^{K+L} > 3^K \implies \frac{K+L}{K} > \frac{\log 3}{\log 2} \approx 1.5849625\dots \]

3 3. การบีบขอบเขตด้วยรูปแบบเชิงเส้นของลอการิทึม (Linear Forms in Logarithms)

Simons และ de Weger ได้กำหนดฟังก์ชันระยะห่าง:

\[ \Lambda = (K+L) \log 2 - K \log 3 \tag{2}\]

3.1 3.1 ขอบเขตบนจากโครงสร้าง \(m\)-Cycle (Upper Bound)

จากการประมาณค่าผลรวมทางขวามือของสมการไดโอแฟนไทน์ จะได้ขอบเขตบนที่ลดลงแบบเอ็กซ์โพเนนเชียล:

\[ 0 < \Lambda < \frac{m}{x_{\min}} \cdot \frac{2}{\log 2} \]

เนื่องจาก Oliveira e Silva ได้ตรวจสอบด้วยคอมพิวเตอร์แล้วว่าไม่มีวัฏจักรใดมี \(x_{\min} < 2^{68}\) ดังนั้น \(\Lambda\) จึงต้องมีขนาด เล็กมากเป็นพิเศษ

3.2 3.2 ขอบเขตล่างจากทฤษฎีบทของเบเกอร์ (Lower Bound via Baker’s Transcendence Theory)

ในทางกลับกัน ทฤษฎีบทการประมาณค่าอตรรกยะของ Alan Baker และผลงานของ Laurent, Mignotte, and Nesterenko (1995) ให้ขอบเขตล่างอย่างเคร่งครัด:

\[ \log \Lambda > -C (\log K)^2 \]

เมื่อนำขอบเขตบนและขอบเขตล่างมาชนกัน จะได้ ขอบเขตจำกัดบนค่า \(K\) และ \(L\) สำหรับค่า \(m\) ใด ๆ

4 4. ทฤษฎีบทหลัก (The Main Theorem)

Importantทฤษฎีบทหลัก (Simons & de Weger, 2005)

สำหรับ \(m\)-cycle ของปัญหา \(3x+1\):

  1. (Brox / Simons & de Weger): สำหรับค่า \(m\) คงที่ใด ๆ จะมี \(m\)-cycle ได้ ไม่เกินจำนวนจำกัด (Finitely many \(m\)-cycles) เสมอ
  2. (Nonexistence for \(m \le 68\)): สำหรับ \(1 \le m \le 68\) ไม่มี nontrivial \(m\)-cycle อื่นใดอยู่จริงบนจำนวนเต็มบวก!

นั่นคือ วัฏจักรแปลกปลอมใด ๆ ที่จะหลงเหลืออยู่ จะต้องมีความสลับซับซ้อนอย่างยิ่งยวด โดยมีจำนวนยอดเขา \(m \ge 69\) และมีความยาวรอบ \(K+L > 10^9\) ตัวเลข!

5 5. การคำนวณเศษส่วนต่อเนื่องของ \(\log_2 3\) สำหรับนิสิต

นิสิตสามารถนำแนวคิดเรื่อง Continued Fractions มาเขียนโปรแกรมคำนวณหาเศษส่วนลู่เข้า (Convergents) ใน Python:

import math


def continued_fraction_log2_3(n_terms: int = 15):
    # คำนวณเศษส่วนต่อเนื่องของ log_2(3)
    val = math.log2(3)
    terms = []
    p = [0, 1]
    q = [1, 0]

    for i in range(n_terms):
        a = int(val)
        terms.append(a)
        val = 1.0 / (val - a)

        p.append(a * p[-1] + p[-2])
        q.append(a * q[-1] + q[-2])

        p_k, q_k = p[-1], q[-1]
        diff = p_k / q_k - math.log2(3)
        print(f"Convergent {i+1:>2}: {p_k:>8} / {q_k:<8} | error = {diff:+.2e}")


continued_fraction_log2_3()

ผลลัพธ์เศษส่วนลู่เข้าสำคัญ:

  • \(p/q = 8/5 = 1.6000\) (ความยาววัฏจักร 8, ก้าวคี่ 5)
  • \(p/q = 19/12 = 1.5833\)
  • \(p/q = 65/41 pprox 1.58536\)
  • \(p/q = 84/53 pprox 1.58490\)
  • \(p/q = 1063/671 pprox 1.5849478\)
