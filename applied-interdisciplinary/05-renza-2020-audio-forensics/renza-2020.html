1 1. ปัญหาการพิสูจน์หลักฐานเสียงดิจิทัล (Audio Forensics Problem)

ในคดีความทางกฎหมาย คลิปเสียงหลักฐานมักถูกนำไปผ่านการลดเสียงรบกวน การบีบอัดไฟล์ (เช่น ส่งผ่าน Line หรือ WhatsApp เป็น MP3/AAC) หรือการปรับระดับเสียง:

  • การดัดแปลงที่ยอมรับได้ (Perceptual / Benign Operations): การบีบอัด MP3, การปรับความดังเล็กน้อย ซึ่งเนื้อหาคำพูดยังคงเดิม \(\implies\) รหัสแฮชจะต้อง ไม่เปลี่ยนหรือเปลี่ยนน้อยมาก (\(BER \approx 0\%\))
  • การโจมตีปลอมแปลงหลักฐาน (Malicious Tampering): การตัดคำพูดบางคำออก, การแทรกเสียงปืน หรือการสลับประโยค \(\implies\) รหัสแฮชจะต้อง เปลี่ยนไปอย่างสิ้นเชิง (\(BER > 25\%\))

2 2. สถาปัตยกรรมการสกัดคุณลักษณะและการใช้ Collatz Binarization

ระบบทำงานผ่าน 3 บล็อกหลัก:

  1. การสกัดคุณลักษณะเสียงด้วย MFCC: ดึงค่า Mel-Frequency Cepstrum Coefficients เพื่อจำแนกลักษณะเสียงพูดของมนุษย์
  2. การลดมิติข้อมูลด้วย PCA: Principal Component Analysis ยุบรวมเวกเตอร์คุณลักษณะให้กระชับ
  3. การแปลงข้อมูลด้วย Collatz Binarization:
    นำสัมประสิทธิ์เด่นมาผ่านฟังก์ชันคอลลัทซ์เพื่อสร้างรหัสไบนารีขนาด 96 บิตที่มีความไวสูงต่อการตัดต่อเสียง แต่ทนทานต่อการบีบอัดไฟล์

3 3. โค้ดตัวอย่าง Python สำหรับจำลอง Collatz Binarization

import numpy as np


def collatz_binarize(value: float, bits: int = 16) -> str:
    # สเกลค่าทศนิยมเป็นจำนวนเต็มบวก
    int_val = int(abs(value) * 1000) % 256 + 1
    code = []
    curr = int_val
    for _ in range(bits):
        code.append(str(curr % 2))
        curr = curr // 2 if curr % 2 == 0 else 3 * curr + 1
    return "".join(code)


print("Collatz 16-bit fingerprint for 0.4285:", collatz_binarize(0.4285))
print("Collatz 16-bit fingerprint for 0.4289:", collatz_binarize(0.4289))
