1 1. ข้อจำกัดของคอลลัทซ์เดี่ยวและวิธีแก้ไข (The Collatz Limitation & Fix)

ปัญหาของการนำฟังก์ชันคอลลัทซ์ปกติมาทำเป็น PRNG คือ วงโคจรจะลู่เข้าสู่ \(4 \to 2 \to 1\) เสมอ ซึ่งทำให้คาบของตัวเลขสุ่มหมดลงอย่างรวดเร็ว

Dziala แก้ปัญหานี้ด้วยการผสาน 2 ระบบเข้าด้วยกัน:

  1. Generalized Collatz Transformation: การคูณและบวกบิตในมอดุโล \(2^{64}\)
  2. Weyl Sequence Generator: ลำดับการบวกค่าคงที่อตรรกยะในมอดุโล \(2^{64}\): \[ w_{n+1} = (w_n + s) \bmod 2^{64} \] โดยที่ \(s\) เป็นจำนวนคี่คงที่ (Odd Increment) ซึ่งตามทฤษฎีบททางคณิตศาสตร์ ลำดับนี้จะ การันตีคาบความยาวเต็มที่เท่ากับ \(2^{64} \approx 1.84 \times 10^{19}\) อย่างแน่นอน

2 2. ขั้นตอนวิธี Collatz-Weyl PRNG (Algorithm Formulation)

ในแต่ละรอบของการปั่นบิต:

\[ \begin{aligned} w &= (w + s) \bmod 2^{64} \\ x &= \begin{cases} (x \gg 1) \oplus w & \text{ถ้า } x \text{ เป็นจำนวนคู่} \\ ((3x + 1) \gg 1) \oplus w & \text{ถ้า } x \text{ เป็นจำนวนคี่} \end{cases} \end{aligned} \]

เมื่อ \(\gg\) คือการเลื่อนบิตไปทางขวา (Bitwise Right Shift) และ \(\oplus\) คือการกระทำ Bitwise XOR

3 3. โค้ดภาษา Python สำหรับทดลองปั่นตัวเลขสุ่ม

import numpy as np


class CollatzWeylPRNG:

    def __init__(self, seed_x: int, seed_w: int, step_s: int = 0xB5AD4ECEDA1CE2A9):
        self.mask64 = 0xFFFFFFFFFFFFFFFF
        self.x = seed_x & self.mask64
        self.w = seed_w & self.mask64
        self.s = step_s | 1  # บังคับให้เป็นจำนวนคี่เพื่อการันตีคาบ 2^64

    def next_uint64(self) -> int:
        self.w = (self.w + self.s) & self.mask64
        if self.x % 2 == 0:
            self.x = ((self.x >> 1) ^ self.w) & self.mask64
        else:
            self.x = (((3 * self.x + 1) >> 1) ^ self.w) & self.mask64
        return self.x

    def random_float(self) -> float:
        return self.next_uint64() / (2**64)


prng = CollatzWeylPRNG(123456789, 987654321)
samples = [prng.random_float() for _ in range(10)]
for i, s in enumerate(samples, 1):
    print(f"Sample {i:>2}: {s:.8f}")
